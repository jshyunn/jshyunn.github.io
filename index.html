제로트러스트 환경 사용자 이상 행위 탐지 연구

국민대학교 대학원 · 석사학위논문

2026.08.19

개요

기존 이상 탐지는 외부에서 들어오는 침입을 막기 위한 경계 기반 기법입니다. 제로트러스트 환경에서는 이미 안으로 들어온 위협을 대상으로 하는 탐지 기법이 필요합니다.

결과
F1-Score 0.98인증 이후 사용자 이상 행위 탐지
Precision 1.00정상 사용자를 공격으로 분류한 사례 없음
AP 0.932비교 기법 7종 중 최고
비교 대상OC-SVM · Isolation Forest · AE · SBERT · LSTM 등
역량
보안 아키텍처 설계 보안 데이터 분석 ML/DL 모델링 위협 식별 오탐 완화
문제 해결 과정
  • 무엇을 탐지 대상으로 삼을 것인가 → 외부에서 들어오는 침입이 아니라, 인증을 통과한 사용자의 행위 변화를 보기로 정함
  • 평가할 데이터가 없음 → 공개 데이터셋에는 인증 이후 행위가 담겨 있지 않아, AWS 테스트베드를 세우고 공격 5종을 직접 수행해 생성
  • 무엇을 정상으로 볼 것인가 → 쓰는 기능이 사람마다 달라, 전체 평균 대신 사용자별 접근 이력을 기준선으로
  • 같은 기능이 여러 URI로 흩어짐 → 숫자·해시 등 동적 값을 Trie로 일반화해 한 템플릿으로
  • 정상 권한 안의 낯선 접근까지 잡힘 → 개인은 처음 쓰더라도 다수가 공통으로 쓰는 URI라면 허용 목록으로 분리
  • 한 번 벗어남을 공격이라 할 수 없음 → 세션 내 신규 URI 비율을 점수화해 임계값과 비교
  • 새로 생긴 기능이 전부 이상으로 잡힘 → HTTP 응답 코드로 되짚어 정상적인 신규 기능 사용은 재분류

Detecting Unknown Cyberattacks on Traffic Management Center in C-ITS

IEEE Communications Magazine (JCR 상위 10%)

2026.01.16

논문 보기 ↗ 코드 보기 ↗
개요

C-ITS 교통관리센터는 차량·노변장비·인프라의 데이터를 모아 실시간 교통 서비스를 운영합니다. 기존 연구는 차량 보안에 몰려 있어, 센터를 노린 미지 공격과 실제 현장 데이터 기반 검증은 비어 있었습니다.

결과
F1-Score 0.99실제 울산 TMC 운영 데이터 평가
98% 압축정상 플로우 22,362개 → 대표 패턴 484개
157만 건/초집합 조회만으로 처리
미지 공격 탐지학습에 없던 신규 패턴 판별
역량
네트워크 트래픽 분석 ML/DL 모델링 보안 요구사항 분석 위협 식별 오탐 완화
문제 해결 과정
  • 무엇을 지킬 것인가 → 기존 연구가 몰려 있는 차량이 아니라, 뚫리면 교통정보 조작과 서비스 마비로 번지는 관리센터를 대상으로 잡음
  • 패킷 내용을 볼 수 없음 → 현장 장비가 암호화해 보내므로, 페이로드 대신 패킷 수·바이트량·지속시간만 쓰기로
  • 알려진 공격만 막아서는 부족 → 시그니처로는 처음 보는 공격을 놓치니, 정상을 학습해 벗어난 것을 찾는 쪽으로
  • 정상 트래픽이 너무 많음 → 운영 트래픽이 규칙적이고 반복된다는 점을 이용해 소수의 대표 패턴으로 압축
  • 값이 조금씩 달라 패턴이 흩어짐 → 로그 변환으로 가까운 값이 같은 구간에 묶이게 함
  • 피처를 늘리자 오탐이 늘어남 → 시그니처 하나가 포괄하는 범위가 좁아져 개수만 불어났고, 로그의 밑을 하이퍼파라미터로 두어 조건이 달라져도 성능이 유지되게 함
  • 근거를 못 대면 현장에서 못 씀 → 정상 대표 패턴에 없다는 사실 자체를 탐지 근거로 제시
